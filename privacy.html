Privacy Policy

Effective date: 13 November 2026

What the app is

Alter ego is a personal assistant application that runs on its owner's own computer and is used by its owner only.

Google data the app accesses

Only after the user grants access on Google's consent screen, the app accesses the user's Google Calendar: calendars, events and their details, as allowed by the permissions the user granted.

How the data is used

Calendar data is used only to carry out the user's own requests, such as showing upcoming events or creating and changing events. It is not used for advertising, not sold, and not used to build profiles.

Processing and sharing

The app runs on the user's own computer, and access tokens are kept there. To answer a request, the app may send the relevant calendar data to the AI model provider that powers the assistant. Data is not shared with anyone else, except where required by law.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The user can revoke the app's access at any time at myaccount.google.com/permissions.

Changes and contact

This policy may be updated; the effective date above shows the latest version. Questions: GitHub issues.
